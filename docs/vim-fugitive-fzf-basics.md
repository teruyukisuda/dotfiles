# fugitive と fzf.vim の基本

Leader は `,`（`.vimrc:57`）。

- `tpope/vim-fugitive`（`rc/dein.toml:34`）
- `junegunn/fzf.vim`（`rc/dein.toml:39`）。fzf 本体は Homebrew 版を `.vimrc:32-33` で runtimepath に追加している

## 1. fzf.vim：ファイル・バッファ・grep をあいまい検索で開く

### 基本操作

どのコマンドでも、画面の下 40% に一覧、右半分にプレビューが出る（`.vimrc:265-266`）。

| キー | 動作 |
|---|---|
| 文字入力 | あいまい検索で絞り込む |
| `Ctrl-j` / `Ctrl-k`（`Ctrl-n` / `Ctrl-p`） | 候補の移動 |
| `Enter` | 開く |
| `Ctrl-t` / `Ctrl-x` / `Ctrl-v` | 新しいタブ / 上下分割 / 左右分割で開く |
| `Tab` | 複数選択（`:Rg` で複数選ぶと quickfix に入る） |
| `Ctrl-/` | プレビューの表示・非表示（`.vimrc:266`） |
| `Esc` | キャンセル |

検索語の書き方: `'foo`（完全一致）、`^src`（前方一致）、`.vim$`（後方一致）、`!test`（除外）、`a | b`（OR）。スペースで区切ると AND。

### キー割り当て（`.vimrc:268-274`）

| キー | コマンド | 内容 |
|---|---|---|
| `,uf` | `:Files` | カレントディレクトリ以下のファイル |
| `,ua` | `:GFiles` | Git 管理下のファイル（`git ls-files`） |
| `,ub` / `sb` | `:Buffers` | 開いているバッファ |
| `,um` | `:History` | 最近開いたファイル |
| `,r` | `:Rg` | ripgrep で全文検索して絞り込む |
| `,R` | `:Rg <カーソル下の単語>` | カーソル下の単語で検索 |
| `sB` / `sT` | `:Windows` | ウィンドウ・タブの一覧 |

### Git 関連（`.vimrc:450-452`）

| キー | コマンド | 内容 |
|---|---|---|
| `,gf` | `:GFiles?` | 変更があるファイル（`git status` の対象）だけを一覧。プレビューは差分 |
| `,gc` | `:BCommits` | 今のファイルのコミット履歴 |
| `,gC` | `:Commits` | リポジトリ全体のコミット履歴 |

### 試す

1. dotfiles で `vim` を起動し、`,ua` → `vimrc` と入力して Enter
2. `,r` → `fugitive` と入力して結果を見る
3. `Tab` で何件か選んで Enter → `]q` / `[q` で quickfix を移動（`.vimrc:141-144`）
4. 単語の上で `,R`

## 2. fugitive：Vim から Git を操作する

`:Git <サブコマンド>` で git のほぼ全機能を Vim の中から実行できる（`:Git log`、`:Git push` など）。中心になるのはステータス画面。

### ステータス画面 `,gs`（`:Git`）

| キー | 動作 |
|---|---|
| `-` | ファイル / ハンクのステージ・アンステージを切り替える |
| `u` | アンステージ |
| `X` | 変更を破棄する（元に戻せない） |
| `=` | その場で差分を展開 / たたむ |
| `)` / `(` | 次 / 前のファイル・ハンクへ移動 |
| `Enter` / `o` | ファイルを開く / 分割して開く |
| `dv` | 左右に並べて差分を表示 |
| `cc` | コミット（メッセージを書いて `:wq`） |
| `ca` | 直前のコミットに追加する（amend） |
| `gq` | 閉じる |
| `g?` | キー一覧のヘルプ |

ステージはファイル単位でもハンク単位でもできる。`=` で差分を展開し、ハンクの上で `-` を押すとそのハンクだけがステージされる。差分の中を `V` で範囲選択してから `-` を押すと、選択した行だけがステージされる。

この環境では、fugitive が標準で `s` に割り当てているステージを外している。`s` 系のウィンドウ操作とぶつかるため（`.vimrc:470`）。ステージは `-` を使う。

### そのほかのキー（`.vimrc:289-294`）

| キー | 内容 |
|---|---|
| `,gd` | `:Gvdiffsplit`。今のファイルをインデックスの内容と左右に並べて比較する。`]c` / `[c` でハンク移動、`do` / `dp` で相手側の内容を取り込む / 相手側へ送る |
| `,gb` | `:Git blame`。行ごとに最後に変更したコミットを表示する。`Enter` でそのコミットを開く |
| `,gl` | `:Git log --oneline -50`。直近 50 件のログ |
| `,gq` | レビュー用に開いたタブと fugitive の画面をまとめて閉じ、普通のファイルのウィンドウを 1 つだけ残す（`.vimrc:307` の `s:ReviewClose`） |
| `,cd` | `:Gcd`。カレントディレクトリをリポジトリのルートに移す（`.vimrc:187`） |

blame からコミットへ飛んだ先の画面には fugitive が `gq` を割り当てないので、`.vimrc:472-474` で `gq` を `:bdelete` に割り当てている。

### `,gr`（`:Review {範囲}`、`.vimrc:338`）

ブランチや PR の差分をまとめてレビューするための自作コマンド。範囲は `git diff` と同じ書き方。

```
:Review master...     " master から分岐した後の変更
:Review HEAD~3        " 3 コミット前から作業ツリーまで
:Review abc123^!      " 1 コミットだけ
:Review A..B
```

- 1 つ目のタブ: 範囲内のコミットと変更ファイルの一覧。ファイル行で `Enter` を押すとそのファイルの差分タブへ、コミット行で `Enter` を押すとコミットを開く
- 2 つ目以降のタブ: ファイルごとの左右差分（`:Git difftool -y` で作成）。`gt` / `gT` で移動
- 終わったら `,gq` でまとめて閉じる
- 範囲なしの `:Review` はステータス画面を開く

## 3. 練習手順

1. `vim .vimrc` で開き、`,gs` でステータス画面を出す
2. `.vimrc` の行で `=` を押して差分を展開し、`)` でハンク間を移動する
3. 1 ハンクの上で `-` を押してステージし、Staged 欄に移ることを確認する。もう一度 `-` で戻す
4. `.vimrc` の行で `dv` を押して左右差分を開き、`]c` でハンク移動。終わったら `,gq`
5. `,gf` で変更ファイルを fzf で開き、プレビューの差分を確認する
6. `,gr` → `HEAD~5` を入力して Enter。一覧のファイル行で Enter → `gt` で移動 → `,gq` で閉じる
7. `,gb` で blame を出し、気になる行で `Enter` を押してコミットを見る → `gq`
8. `,gC` で全体のコミット履歴を fzf で検索する

`X` と `cc` は実際にファイルやコミットを変更する。練習するときは、捨ててもよい変更で試すか、別ブランチで試す。
