# fugitive と fzf.vim の基本

よく使うキーは `<Space>` 始まりの 2 ストロークにしてある（`.vimrc:262-267`, `.vimrc:295-300`）。
この文書のキーはすべて `<Space>` の方で書く。`,uf` `,gs` のような `,`（Leader、`.vimrc:57`）始まりの同じキーも残っている。
`<Space>` のキーが無いもの（`,gr` `,gb` `,gl` `,gC` `,cd`）だけ `,` で書く。

- `tpope/vim-fugitive`（`rc/dein.toml:31`）
- `junegunn/fzf.vim`（`rc/dein.toml:36`）。fzf 本体は Homebrew 版を `.vimrc:32-33` で runtimepath に追加している

---

## 1. fzf.vim：ファイル・バッファ・grep をあいまい検索で開く

### 1-1. 起動する（`.vimrc:262-267`, `.vimrc:179-181`, `.vimrc:291-293`, `.vimrc:298-299`）

| キー | コマンド | 一覧に出るもの |
|---|---|---|
| `<Space>f` | `:Files` | カレントディレクトリ以下のファイル |
| `<Space>a` | `:GFiles` | Git 管理下のファイル（`git ls-files`） |
| `<Space>m` | `:History` | 最近開いたファイル |
| `sb` | `:Buffers` | 開いているバッファ |
| `sB` / `sT` | `:Windows` | ウィンドウ・タブ |
| `<Space>r` | `:Rg` | ripgrep で全文検索した行 |
| `<Space>R` | `:Rg <カーソル下の単語>` | カーソル下の単語で検索した行 |
| `<Space>e` | `:GFiles?` | 変更があるファイル（`git status` の対象）。プレビューは差分 |
| `<Space>c` | `:BCommits` | 今のファイルのコミット履歴 |
| `,gC` | `:Commits` | リポジトリ全体のコミット履歴 |

### 1-2. 画面の見方

どのコマンドでも、画面の下 40% に fzf の画面が開き、その右半分にカーソル位置の候補のプレビューが出る（`.vimrc:247-248`）。
入力欄に文字を打つと、一覧がその場で絞り込まれる。

### 1-3. 画面の中の操作

| キー | 動作 |
|---|---|
| 文字入力 | あいまい検索で絞り込む |
| `Ctrl-j` / `Ctrl-k`（`Ctrl-n` / `Ctrl-p`） | 候補の移動 |
| `Enter` | 開く |
| `Ctrl-t` / `Ctrl-x` / `Ctrl-v` | 新しいタブ / 上下分割 / 左右分割で開く |
| `Tab` | 複数選択（`:Rg` で複数選ぶと quickfix に入る） |
| `Alt-a` / `Alt-d` | `:Rg` で全選択 / 全解除。ターミナル側で Option キーを Meta として送る設定が要る |
| `Ctrl-/` | プレビューの表示・非表示（`.vimrc:248`） |
| `Esc` | キャンセル |

### 1-4. 絞り込みの書き方

| 書き方 | 意味 |
|---|---|
| `foo bar` | スペースで区切ると AND |
| `'foo` | 完全一致 |
| `^src` | 前方一致 |
| `.vim$` | 後方一致 |
| `!test` | 除外 |
| `a \| b` | OR |

- `:Rg` の絞り込みは「ファイル名:行:列:本文」の行全体が対象になる。検索語にファイル名の一部を足せば、ファイルでも絞れる
- `:Rg` は `.vimrc` のような `.` 始まりのファイルも検索する。`.git` の中は検索しない。fzf.vim 標準の `:Rg` には `--hidden` が無いので、`.vimrc:250-252` で `--hidden --glob '!.git'` を付けて定義し直している

## 2. fugitive：Vim から Git を操作する

`:Git <サブコマンド>` で git のほぼ全機能を Vim の中から実行できる（`:Git log`、`:Git push` など）。中心になるのはステータス画面。

### 2-1. 起動する（`.vimrc:283-288`, `.vimrc:296-297`, `.vimrc:300`）

| キー / コマンド | 開くもの |
|---|---|
| `<Space>s`（`:Git`） | ステータス画面（2-2） |
| `<Space>d`（`:Gvdiffsplit`） | 今のファイルとインデックスの内容の左右差分（2-3） |
| `:Gvdiffsplit {リビジョン}` | 今のファイルと、指定したリビジョンの内容の左右差分（例: `:Gvdiffsplit HEAD~5`） |
| `,gb`（`:Git blame`） | 行ごとに最後に変更したコミットを並べた blame 画面（2-3） |
| `,gl`（`:Git log --oneline -50`） | 直近 50 件のログ画面（2-3） |
| `:{範囲}Gclog` | 選択した行範囲を変更したコミットを quickfix に並べる（`git log -L`）。`]q` / `[q` で順に見る |
| `,gr`（`:Review {範囲}`） | 範囲内の変更の一覧と、ファイルごとの差分タブ（2-4） |

開いた画面を閉じるのは、その画面での `gq` か、`<Space>q`。`<Space>q` はレビュー用に開いたタブと fugitive の画面をまとめて閉じ、普通のファイルのウィンドウを 1 つだけ残す（`autoload/review.vim:17` の `review#close`）。

画面を開かずに使うもの:

| キー / コマンド | 内容 |
|---|---|
| `:Gread` | 今のバッファをインデックスの内容で置き換える（保存はしない）。ファイルの変更を全部捨てたいとき |
| `:Gwrite` | 保存してステージする（`git add`） |
| `,cd`（`:Gcd`） | カレントディレクトリをリポジトリのルートに移す（`.vimrc:189`） |

### 2-2. ステータス画面の操作

| キー | 動作 |
|---|---|
| `-` | ファイル / ハンクのステージ・アンステージを切り替える |
| `u` | アンステージ |
| `X` | 変更を破棄する。元に戻すためのコマンドが表示される（`:messages` で再表示） |
| `=` | その場で差分を展開 / たたむ |
| `)` / `(` | 次 / 前のファイル・ハンクへ移動 |
| `Enter` / `o` | ファイルを開く / 分割して開く |
| `dv` | 左右に並べて差分を表示 |
| `cc` | コミット（メッセージを書いて `:wq`） |
| `ca` | 直前のコミットに追加する（amend） |
| `gq` | 閉じる |
| `g?` | キー一覧のヘルプ |

ステージはファイル単位でもハンク単位でもできる。`=` で差分を展開し、ハンクの上で `-` を押すとそのハンクだけがステージされる。差分の中を `V` で範囲選択してから `-` を押すと、選択した行だけがステージされる。`X` も `V` で範囲選択して使える。

この環境では、fugitive が標準で `s` に割り当てているステージを外している。`s` 系のウィンドウ操作とぶつかるため（`.vimrc:309`）。ステージは `-` を使う。

### 2-3. 差分・blame・ログ画面の操作

| 画面 | キー | 動作 |
|---|---|---|
| 左右差分（`<Space>d`） | `]c` / `[c` | 次 / 前のハンクへ |
| | `do` | 相手側（インデックス）の内容を取り込む |
| blame（`,gb`） | `Enter` | その行を変更したコミットを開く |
| | `gq` | blame を閉じる |
| ログ（`,gl`） | `Enter` | カーソル行のコミットを開く |
| | `gq` | ログ画面を閉じる |
| コミット | `gq` | コミットの画面を閉じる |

blame からコミットへ飛んだ先の画面には fugitive が `gq` を割り当てないので、`.vimrc:311-313` で `gq` を `:bdelete` に割り当てている。

### 2-4. `,gr`（`:Review {範囲}`、`plugin/review.vim:2`、実装は `autoload/review.vim:66` の `review#start`）

ブランチや PR の差分をまとめてレビューするための自作コマンド。範囲は `git diff` と同じ書き方。

```
:Review master...     " master から分岐した後の変更
:Review HEAD~3        " 3 コミット前から作業ツリーまで
:Review abc123^!      " 1 コミットだけ
:Review A..B
```

- 1 つ目のタブ: 範囲内のコミットと変更ファイルの一覧。ファイル行で `Enter` を押すとそのファイルの差分タブへ、コミット行で `Enter` を押すとコミットを開く
- 2 つ目以降のタブ: ファイルごとの左右差分（`:Git difftool -y` で作成）。`gt` / `gT` で移動
- 終わったら `<Space>q` でまとめて閉じる
- 範囲なしの `:Review` はステータス画面を開く

## 3. 手を動かして試す

dotfiles リポジトリそのものを題材にする。上から順にやると 30 分ほどかかる。
各項目の「なしだと」は、プラグインを使わずに同じことをする手順。比べてみて差を感じなければ、そのプラグインは要らない。

### 3-0. 準備

コミットや破棄もするので、練習用のブランチを切る。最後（3-9）で消す。

未コミットの変更があると、3-4 の `X` でまとめて消してしまうおそれがある。先にコミットするか、`git stash` で退避しておく。

```sh
cd ~/dotfiles
git status            # 変更が残っていれば git stash
git switch -c practice
vim .vimrc
```

### 3-1. 名前をうろ覚えのファイルを開く

「review の vim ファイル、どのディレクトリだったか」という状況。

1. `<Space>a` を押し、`review` と打つ。`plugin/review.vim` `autoload/review.vim` と `docs/` の 2 ファイルが残る
2. `revvim` に打ち直す。並んでいない文字を飛ばして当てるので、`review.vim` の 2 つだけになる
3. 続けてスペースと `^auto` を足す（`revvim ^auto`）。`autoload/review.vim` だけになる
4. プレビューで中身を確かめてから `Enter`
5. もう一度 `<Space>a` → `revvim !auto` → `Ctrl-v`。`plugin/review.vim` が左右分割で開く

なしだと: ディレクトリ名を思い出して `:e autoload/re<Tab>`。思い出せなければ、シェルで `find . -name '*review*'` を打ってから開き直す。

### 3-2. 開いたファイルの間を行き来する

1. 3-1 の続き。いま `.vimrc` `autoload/review.vim` `plugin/review.vim` が開いている
2. `sb` → `vimrc` → `Enter` で `.vimrc` に戻る
3. `sb` → `plug` → `Enter` で `plugin/review.vim` へ。2〜3 文字打てば足りる
4. vim を `:qa` で終了し、もう一度 `vim` だけで起動して `<Space>m`。前回開いたファイルが並んでいる

なしだと: `:ls` で番号を読んでから `:b 3`。前回開いたファイルは `:browse oldfiles` で一覧を出して番号を打つ。

### 3-3. どこで使っているかを探して飛ぶ

「`review#start` がどこで定義され、どこから呼ばれているか」を探す。

1. `<Space>r` → `review#start` と打つ。`autoload/review.vim`（定義）、`plugin/review.vim`（呼び出し）、`docs/` の行が並び、右にその行の前後が出る
2. 続けて `!docs/` を足す（`review#start !docs/`）。`docs/` の行が消えて 2 行になる
3. `plugin/review.vim` の行で `Enter`。その行に飛ぶ
4. 飛んだ先の `review#start` の上にカーソルを置き、`<Space>R`。カーソル下の単語でそのまま検索される。`autoload/review.vim` の行で `Enter` で定義に飛ぶ


なしだと: `:grep Gvdiffsplit` → `:copen` → 行を上下して `Enter`。中身を確かめるには一度飛ぶしかない。

### 3-4. 複数ファイルを一括置換し、差分を確かめて捨てる

fzf の複数選択と fugitive の破棄を組み合わせる。

1. `<Space>r` → `ステータス画面` と打つ。`docs/`、`.vimrc`、`.bashrc`、`autoload/review.vim` のあちこちが出る
2. `Alt-a` で全選択（効かなければ `Tab` で何件か選ぶ）→ `Enter`。選んだ行が quickfix に入り、1 件目に飛ぶ
3. 次のコマンドで、quickfix の全行を置換して保存する

   ```vim
   :cdo s/ステータス画面/STATUS画面/g | update
   ```

4. `<Space>e`。変更のあったファイルが並び、右に差分が出る。`Ctrl-j` / `Ctrl-k` で一覧を移動して、ファイルごとの差分を確かめる。`Esc` で閉じる
5. `<Space>s` でステータス画面を開く。Unstaged 欄のファイルの行で `X` を押して破棄する。ファイルの数だけ繰り返す（Unstaged 欄の行を `V` でまとめて選んでから `X` でもよい）
6. `gq` で閉じ、`:cclose` で quickfix を閉じる

なしだと: `rg -l ステータス画面 | xargs sed -i '' 's/…/…/g'` → `git diff` → `git checkout -- <ファイル>`。置換の前に対象の行を目で選ぶことはできない。

### 3-5. 変更の一部だけをコミットする

1. `.vimrc` で `gg` → `O` → `" practice 1` と打って `Esc`
2. `G` → `o` → `" practice 2` と打って `Esc` → `:w`
3. `<Space>s` → Unstaged 欄の `.vimrc` の行で `=`。ハンクが 2 つ並ぶ
4. 1 つ目のハンク（`+" practice 1`）の上で `-`。Staged 欄に `.vimrc` が出る。Unstaged 欄にも `.vimrc` が残り、そこには 2 つ目のハンクだけがある
5. `cc` → 1 行目に `practice 1` と書いて `:wq`
6. `,gl` でログを開く。先頭の `practice 1` の行で `Enter`。差分に `" practice 1` だけが入っている
7. `<Space>q` で、コミットの画面とログ画面をまとめて閉じる

なしだと: `git add -p` で、ハンクごとに y / n を答えていく。ハンクの前後を見返すことはできない。

### 3-6. 1 つのハンクだけ元に戻す

3-5 で残った `" practice 2` を、ファイルを開いたまま戻す。

1. `.vimrc` を開いた状態で `<Space>d`。左右に分かれ、`.vimrc` とインデックスの内容が並ぶ
2. 右側が作業ツリーの `.vimrc`。カーソルが左にあれば `sl` で右に移り、`gg` → `]c`。`" practice 2` の行に止まる（`practice 1` はコミット済みなので差分にならない）
3. `do` を押す。インデックス側の内容が取り込まれ、`" practice 2` の行が消える
4. `:w` → `<Space>q` で比較用の画面を閉じる
5. `<Space>s` で、`.vimrc` が Unstaged 欄から消えていることを確かめる → `gq`

なしだと: `git diff` で該当箇所を探し、手で消す。または `git checkout -p` で、ハンクごとに y / n を答えていく。

### 3-7. この行がなぜこうなっているかを調べる

1. `.vimrc` で `/nnoremap sq` と検索して、その行に移る
2. `,gb`。左に各行のコミットハッシュ・作者・日付が出る。`sq` の行は `ff7b63a5`
3. その行で `Enter`。コミット `feat: map sq to :bd and drop sQ` が開く。何を変えたコミットかが、メッセージと差分で分かる
4. `gq` で `.vimrc` に戻る

なしだと: シェルで `git blame -L '/^nnoremap sq/,+1' .vimrc` → 出てきたハッシュで `git show ff7b63a5`。

### 3-8. ある範囲の変更履歴をたどる

「`s` 系のウィンドウ操作のキーが、いつどう変わってきたか」を見る。

1. `.vimrc` で `/nnoremap s <Nop>` と検索して移る → `V` → `/sT` と打って `Enter`。`s` 系の行がまとめて選ばれる
2. `:` を押すと `:'<,'>` が入るので、続けて `Gclog` と打って `Enter`
3. quickfix にコミットが 5 件並び、1 件目の内容が開く。各行には、そのコミットのメッセージが出ている
4. `]q` / `[q` で古い方・新しい方へ移る。そのコミットで範囲がどう変わったかが見られる
5. `:cclose` → `:e .vimrc` で作業ファイルに戻る

ファイル全体の履歴なら、`<Space>c` の方が手早い。コミットを選ぶと、右のプレビューにそのコミットの差分が出る。

なしだと: シェルで `git log -L '/nnoremap s <Nop>/,/sT/:.vimrc'`。

### 3-9. 過去のバージョンと比べ、後片付けをする

1. `.vimrc` で `:Gvdiffsplit HEAD~5`。5 コミット前の `.vimrc` と左右に並ぶ。`]c` で違う箇所を順に見る
2. `<Space>q` で閉じる
3. 練習用のブランチを消す。vim の中から

   ```vim
   :Git switch main
   :Git branch -D practice
   ```

   `:Git branch -D` は practice のコミット（`practice 1`）ごと消す。3-0 で `git stash` した場合は、`:Git stash pop` で戻す。

なしだと: `git diff HEAD~5 -- .vimrc`。上下に流れる差分を読むことになる。
